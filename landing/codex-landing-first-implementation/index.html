GET STARTED

Get started in minutes.

Decktation installs through Decky Loader. No extra Linux packages are required.

Download and install Decky Loader
1. Enable developer mode

Open Decky Settings and turn on Developer Mode.

2. Install Plugin from URL

In Decky’s developer options, choose Install Plugin from URL. Paste the URL below and confirm the installation.

https://silverfoxy.github.io/decktation/latest.zip
3. Open Decktation and enable it

Open Decktation from Decky, choose your game preset and language, and enable it.

4. Dictate in any text field

Focus a text field in your game or app. Hold L1 + R1 (the default shortcut), speak, then release both buttons. Your message will be typed into the field.

URL installations require manual updates until the official Decky Store listing is available.

FAQ

Questions, answered.

Does Decktation need internet?

A connection is needed to download a Whisper model the first time. Dictation itself is processed locally once the model is available.

Is my voice uploaded anywhere?

No. Audio and transcripts are processed locally. Optional diagnostics are separate and opt-in.

Does it only work with World of Warcraft?

No. Decktation includes WoW, Guild Wars 2 and Generic behavior for other compatible text fields.

How fast is transcription?

Speed depends on the selected model, hardware and game load. Supported AMD hardware can use Vulkan acceleration.

Is Decktation open source?

Yes. The source code, releases and issue tracker are available on GitHub.

Which SteamOS devices are supported?

Designed for Steam Deck and controller-driven SteamOS systems. Hardware and controller compatibility can vary.

Does it work offline?

Once the required Whisper model is downloaded, dictation is processed locally without a cloud transcription service.

Why does the plugin need elevated permissions?

Decktation reads controller input and enters text through Decky permissions. Dictated text is handled as data, never executed as a shell command.
