INSTALACIÓN

¿Ya tienes Decky Loader?

Instala Decktation

  1. Activa el modo desarrollador

    Abre los ajustes de Decky y activa el modo desarrollador.

    ¿Por qué el modo desarrollador?

    Decktation está pendiente de aprobación en la tienda oficial de Decky. La instalación directa por URL requiere actualmente el modo desarrollador de Decky.

  2. Instala Decktation

    Opción A · Instalar desde URL

    Elige Instalar plugin desde URL en las opciones de desarrollador de Decky. Pega esta URL y confirma.

    https://silverfoxy.github.io/decktation/latest.zip
    Opción B · Instalar desde ZIP

    Descarga el ZIP en tu Steam Deck. En el modo juego, abre Ajustes de Decky → Desarrollador → Instalar plugin desde ZIP, selecciona el archivo descargado y confirma. No necesitas escribir la URL.

    Descargar ZIP de Decktation

  3. Abre Decktation y empieza a dictar

    Elige tu juego e idioma y activa Decktation. Colócate en un campo de texto, mantén L1 + R1, habla y suelta para escribir tu mensaje.

La instalación directa requiere actualizaciones manuales.

Configura Decky primero

Decky se configura una sola vez. Una vez instalado, los plugins se gestionan desde el modo juego.

No necesitas usar la terminal.

  1. Cambia al modo escritorio

    En tu Steam Deck, pulsa el botón Steam, abre el menú de encendido y selecciona Cambiar a escritorio. Espera a que aparezca el escritorio.

  2. Descarga el instalador oficial

    Haz esta parte en tu dispositivo SteamOS.

    Una vez en el modo escritorio de tu Steam Deck, abre Firefox u otro navegador web. Escribe decky.xyz/download en la barra de direcciones para descargar el instalador oficial.

    decky.xyz/download

    Descargar el instalador oficial de Decky

  3. Abre el instalador descargado y elige Latest Release (versión estable).

    El instalador te guiará para conceder permisos de administrador. Si ya tienes una contraseña de administrador, introdúcela cuando la pida. Si no, te ofrecerá crear una contraseña temporal y eliminarla al terminar. No necesitas crearla antes ni usar la terminal.

    Solución de problemas: la descarga de Firefox no se abre

    Si Firefox llama al archivo decky_installer.desktop.download, renómbralo a decky_installer.desktop. Muévelo al escritorio y haz doble clic para abrirlo.

  4. Usa Return to Gaming Mode (volver al modo juego).

FAQ

Preguntas, resueltas.

¿Decktation necesita Internet?

Necesitas conexión para descargar un modelo Whisper la primera vez. Después, el dictado se procesa localmente.

¿Se sube mi voz a algún sitio?

No. El audio y las transcripciones se procesan localmente. Los diagnósticos opcionales son independientes y requieren consentimiento.

¿Sólo funciona con World of Warcraft?

No. Decktation incluye comportamiento para WoW, Guild Wars 2 y modo Generic para otros campos de texto compatibles.

¿Qué tan rápida es la transcripción?

Los mensajes cortos pueden estar listos en menos de un segundo después de soltar los botones. El tiempo varía según tu dispositivo, el modelo elegido, la duración del mensaje y la carga del juego.

¿Decktation es de código abierto?

Sí. El código, las versiones y el seguimiento de incidencias están en GitHub.

¿Qué dispositivos SteamOS son compatibles?

Diseñado para Steam Deck y sistemas SteamOS controlados con mando. La compatibilidad del hardware y del mando puede variar.

¿Funciona sin conexión?

Una vez descargado el modelo Whisper necesario, el dictado se procesa localmente sin un servicio en la nube.

¿Por qué necesita permisos elevados?

Decktation lee el mando e introduce texto mediante los permisos de Decky. El dictado se trata como datos y nunca se ejecuta como una orden del sistema.

¿Buscas versiones de prueba?

Consulta las versiones y builds de desarrollo para probar los próximos cambios y compartir tus comentarios.
